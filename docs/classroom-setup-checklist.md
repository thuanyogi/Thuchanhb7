# Classroom Setup Checklist

## Instructor Machine
- [ ] Google Antigravity installed and opens successfully.
- [ ] Demo account ready.
- [ ] Source decks accessible from `assets/source-materials/original/`.
- [ ] Student template accessible from `assets/templates/student-antigravity-workspace/`.
- [ ] Backup output or screenshots ready.

## Student Readiness
- [ ] Antigravity access confirmed.
- [ ] Class folder created.
- [ ] Student has a simple business or study case.
- [ ] Student understands not to upload private secrets or sensitive raw data.

## Demo Data
- [ ] Sample data is safe to share.
- [ ] Data size is small enough for class time.
- [ ] Expected output format is known.

## Failure Backup
- [ ] If account/quota fails: analyze provided sample workspace.
- [ ] If live UI changes: use current official docs and instructor walkthrough.
- [ ] If data unavailable: use sample-data folder in student template.
