## Phương pháp xuyên suốt
- PDCA: Plan, Do, Check, Act cho cải tiến liên tục.
- OIPO: Objective, Input, Process, Output cho workflow.
- MICRO: khung mô tả agent theo nhiệm vụ, input, constraint, role, output.
- CLEAR: khung viết rules rõ ràng, kiểm chứng được.
- SCOPE: khung xác định đề bài cuối khóa.
