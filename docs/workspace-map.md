# Workspace Map

## Purpose
Map nhanh các lớp của workspace dạy Antigravity.

## Folders
| Folder | Owner | Purpose |
| --- | --- | --- |
| `.claude/agents/` | Giảng viên | Agent hỗ trợ course architecture, lesson prep, review, audit |
| `.claude/commands/` | Giảng viên | Command chuẩn bị lesson, tạo student workspace, review demo |
| `.claude/skills/` | Giảng viên | Course context và chuẩn giảng dạy |
| `.claude/workflows/` | Giảng viên | Quy trình lesson prep, student lifecycle, demo review |
| `docs/` | Giảng viên và học viên | Tài liệu đọc trực tiếp |
| `docs/lesson-prep/` | Giảng viên | Giáo án 11 buổi học và hướng dẫn buổi 12 thuyết trình dự án |
| `docs/student/` | Học viên | Handbook và quickstart |
| `docs/assessment/` | Giảng viên | Rubric chấm điểm |
| `assets/source-materials/original/` | Source owner | File PDF/HTML gốc, không chỉnh trực tiếp |
| `assets/source-materials/derived/` | Giảng viên | OCR, trích xuất, handout tạo từ nguồn |
| `assets/templates/student-antigravity-workspace/` | Học viên | Starter workspace cuối khóa |
| `plans/` | Người triển khai | Kế hoạch, report, validation |
