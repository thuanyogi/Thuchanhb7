# Project Presentation Rubric

Use `docs/assessment/assessment-rubric.md` as the canonical scoring rubric.

## Project Presentation Focus
- Workspace runs end-to-end.
- Output quality reaches the course target.
- Student explains design choices and trade-offs.
- Student shows at least 3 PDCA loops.
- Student handles failure honestly.

## Minimum Evidence
- Project brief.
- Workspace map.
- Live run or accepted fallback.
- Output sample.
- PDCA log.
- Project presentation checklist.
