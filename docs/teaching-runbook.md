# Teaching Runbook

## Weekly Rhythm
1. Before class: open the lesson file in `docs/lesson-prep/`.
2. Check source deck in `assets/source-materials/original/`.
3. Prepare demo data and fallback output.
4. During class: keep lecture short and practice artifact-focused.
5. After class: collect artifacts, update known issues, remind PDCA log.

## Lesson Prep Checklist
- [ ] Lesson objective is clear.
- [ ] Source deck is available.
- [ ] Live demo has sample input.
- [ ] Practice task can be finished in class.
- [ ] Assignment is tied to final project.
- [ ] Backup activity exists.

## Class Cadence
- 0-10 minutes: objective and expected artifact.
- 10-80 minutes: concept and live demo.
- 80-90 minutes: checkpoint.
- 90-170 minutes: guided practice.
- 170-180 minutes: artifact review and assignment.

## Post-Class Review
- What failed in tool/setup?
- What confused students?
- Which artifact quality was weak?
- What should be changed before next cohort?
