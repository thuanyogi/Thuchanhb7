=== PAGE 9 ===
MCP là gì?
MCP = Model Context Protocol
Cách AI sử dụng các công cụ bên ngoài để thực hiện hành động thực tế trong thế giới số.
MCP cho phép AI không chỉ "nghĩ" mà còn "làm" — thực thi hành động trong hệ thống thực tế.
Trong buổi học này
GG Anti gọi Python file
Python thực thi logic xử lý
Kết quả ghi vào hệ thống thật
→  Đó chính là MCP hoạt động

ĐỀ BÀI: TỰ ĐỘNG HÓA ĐỒNG BỘ DỮ LIỆU GOOGLE SHEETS BẰNG PYTHON
1.Tình huống doanh nghiệp: 
Tại công ty ABC, hàng ngày các nhân viên đi công tác phải nhập các khoản chi tiêu (ngày tháng, tên nhân viên, hạng mục,
số tiền) vào một file Google Sheet chung mang tên Data_Nhan_Vien (Link)
Bộ phận Kế toán (Admin) có một file tổng hợp riêng mang tên Admin Expense Tracker (Link) để lưu trữ dài hạn và làm báo
cáo.
2. Vấn đề hiện tại: 
Cứ mỗi cuối ngày, nhân sự phòng kế toán phải vào file của nhân viên, copy bằng tay những dòng dữ liệu mới phát sinh trong
ngày và paste nối tiếp xuống cuối file Admin. 
Thao tác này thủ công, tốn thời gian, dễ copy sót hoặc copy trùng lặp dữ liệu của ngày hôm trước.

=== PAGE 23 ===
3. Yêu cầu dành cho Học viên: Đóng vai là một Chuyên gia Tự động hóa, bạn hãy viết một kịch bản lập trình (Script) bằng ngôn
ngữ Python giải quyết triệt để bài toán này với các tiêu chí khắt khe sau, SỬ DỤNG GOOGEL ANTIGRAVITY ĐỂ HƯỚNG
DẪN/THỰC HIỆN: 
Kết nối an toàn: Phải sử dụng phương thức xác thực chuẩn của Google Cloud (OAuth 2.0 thông qua file credentials.json) để
kết nối Python với Google Sheets. Không dùng các phương pháp kém bảo mật.
Ghi dữ liệu thông minh (Không ghi đè): Chương trình phải tự động phát hiện được dòng trống dưới cùng của file Admin
Expense Tracker và chèn nối tiếp (append) dữ liệu mới xuống phía dưới. Tuyệt đối không được làm xóa hay ghi đè lên dữ
liệu cũ của Kế toán.
Chống trùng lặp (Anti-duplication): Sau khi copy thành công dữ liệu mới sang file Admin, chương trình phải quay lại file
Data_Nhan_Vien, tự động tạo/tìm cột trạng thái (SyncStatus) và đánh dấu "Done" cho các dòng vừa xử lý. Ở những lần chạy
code tiếp theo, chương trình chỉ được bốc những dòng chưa có chữ "Done".
