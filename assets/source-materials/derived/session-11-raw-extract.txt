Handoff Là Gì?
Bàn giao dữ liệu (Handoff) là quá trình chuyển giao
thông tin từ đầu ra (Output) của Agent này làm đầu vào
(Input) của Agent tiếp theo.
Đảm bảo luồng chạy tự động liên tục mà không cần con
người thao tác trung gian.
Thách Thức & Giải Pháp
Thách thức: Nếu định dạng đầu ra của Agent trước bị
lệch cấu trúc, hệ thống sẽ gãy luồng (crash).
Ví dụ lỗi: Agent CV Screener trả về khóa ma_uv,
nhưng Agent Test Evaluator lại tìm khóa
ma_ung_vien →  lỗi hệ thống.
Giải pháp: Sử dụng định dạng JSON chuẩn hóa với các
khóa (keys) được thống nhất trước trong Knowledge
Base.
Handoff dữ liệu giữa các tầng AI

Khái Niệm & Mục Tiêu
Schema là bản định nghĩa cấu trúc dữ liệu bắt buộc, gồm tên
trường, kiểu dữ liệu và các giá trị được chấp nhận.
Mục tiêu: Ép các mô hình LLM vốn có tính ngẫu nhiên cao
phải trả về đúng cấu trúc mong muốn.
Tầm quan trọng: Bảo vệ hệ thống trước sự biến đổi tự do
của LLM.
Cách làm: Viết hướng dẫn định dạng JSON cực kỳ chi tiết
kèm ví dụ mẫu (Few-shot prompting) trong System
Prompt của Agent.
Mẫu JSON Schema Chuẩn
{
  "ma_uv": "string (bắt buộc)",
  "diem_cv": "float (0.0 - 10.0)",
  "status": "Valid | Invalid"
}
Schema chuẩn hóa = Hệ thống ổn định
Xây dựng Schema Handoff

=== PAGE 11 ===
Kiểm thử tích hợp là gì?
Kiểm tra sự phối hợp của các Agent sau khi lắp ráp vào luồng
chung — không chỉ kiểm tra từng Agent đơn lẻ.
Tại sao cần?
Từng Agent chạy đơn lẻ có thể đúng, nhưng khi lắp vào luồng
chung rất dễ phát sinh lỗi lệch data type, nghẽn dữ liệu.
Phương pháp kiểm thử
Ví dụ: Đưa 30 bộ dữ liệu thực tế vào hệ thống, bao gồm:
Happy Path: Trường hợp dữ liệu chuẩn, đầy đủ thông tin
Edge Cases: Trường hợp lỗi cố ý — thiếu trường, sai định
dạng, nộp trễ
Boundary Cases: Điểm cận biên 6.0 – 6.9 kích hoạt Human
Checkpoint
Mục tiêu: Đạt độ tin cậy 100% sau vòng lặp PDCA
Phương pháp kiểm thử tích hợp hệ thống

Yêu Cầu Nghiệp Vụ
VD: Doanh nghiệp yêu cầu nộp bài thi đúng thời hạn cấu hình. Ứng viên
nộp trễ sẽ bị trừ điểm phạt.
Quy Tắc Phạt
Nếu bài thi nộp sau deadline →  trạng thái nộp = "Trễ hạn"
Trừ 2.0 điểm phạt từ điểm gốc
Ví dụ áp dụng: UV-004, UV-011, UV-023
Logic An Toàn (Safety Guard)
Điểm sau phạt không được nhỏ hơn 0.0. Công thức bắt buộc:
Nếu không có Safety Guard: ứng viên đạt 1.5 điểm nộp trễ →
điểm âm (-0.5) →  lỗi tính toán toàn hệ thống!

=== PAGE 19 ===
ĐỀ BÀI : TỰ ĐỘNG HÓA TUYỂN DỤNG (HR TalentOps Agentic System)
Bối cảnh: Tự động lọc hồ sơ, tính điểm test, duyệt tay và gửi email cho 30 ứng viên AI Engineer.
1. Yêu cầu hệ thống (Các Agent cần xây dựng)
CV Screener: Đọc CV, tính điểm CV, phát hiện lỗi.
Test Evaluator: Chấm điểm test, phạt nộp trễ.
HR Director (Orchestrator): Tính điểm tổng, chạy duyệt tay cận biên, xuất báo cáo.
Communication Agent: Tạo email kết quả tự động.
Human Checkpoint: Dừng màn hình để HR nhập P (Pass) hoặc F (Fail) cho ứng viên cận biên.
2. Dữ liệu đầu vào
danh_sach_cv.xlsx (Mã UV, Họ tên, Email, SĐT, Kỹ năng, Số năm KN). Link
ket_qua_bai_test.xlsx (Mã UV, Điểm trắc nghiệm, Điểm tự luận, Trạng thái nộp). Link
3. Quy tắc tính điểm & Phân loại
Lọc lỗi: Trống Tên/Email/SĐT hoặc Email thiếu @  ➔  INVALID (gửi email yêu cầu bổ sung).
Điểm CV: Sàn 5đ. Cộng 2đ (KN >= 2 năm), cộng 1đ (KN >= 4 năm). Cộng 0.5đ/mỗi kỹ năng khớp JD (python, llm, langchain,
langgraph, prompt engineering, claude, gemini). Tối đa 10đ.
Điểm Test: (Trắc nghiệm + Tự luận) / 2. Nộp trễ ("Tre han") ➔  Trừ 2đ. Thiếu điểm ➔  Điểm bằng 0.
Điểm Tổng hợp: Diem_CV * 40% + Diem_Test * 60%.
Phân loại:
>= 7.0  ➔  PASS (Gửi email mời phỏng vấn).
< 6.0  ➔  FAIL (Gửi email từ chối).
6.0 đến < 7.0  ➔  Human Checkpoint (Dừng để HR duyệt tay).
4. Kết quả đầu ra
File Excel ket_qua_tuyen_dung.xlsx và thư mục emails/ chứa 30 file thư .txt tương ứng.

Validation Dữ Liệu Bài Thi
Nếu thiếu điểm trắc nghiệm hoặc tự luận →  Gắn trạng thái Invalid. Ví
dụ: UV-027 bị thiếu điểm tự luận.
Tính Điểm Trung Bình Bài Test
Công thức: Điểm test = (Trắc nghiệm + Tự luận) / 2 — áp dụng cho
tất cả hồ sơ hợp lệ.
Áp Dụng Phạt Trễ Hạn
Nếu trạng thái nộp = "Trễ hạn" →  Điểm sau phạt = max(0.0, điểm
gốc − 2.0). Ví dụ: UV-004, UV-011, UV-023.
Trả Về Kết Quả
Trả về dict kết quả bài test được index bằng Mã ứng viên (ma_uv) —
sẵn sàng cho Handoff sang bước tiếp theo.
