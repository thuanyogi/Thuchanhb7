Khung MICRO

MICRO — JD Cho Nhân Viên AI

Năm thành phần bắt buộc. Thiếu một phần → Agent hoạt động sai hoặc không nhất quán.

M
Mission
Nhiệm vụ cụ thể của Agent là gì?
💡 "Nhân viên giỏi nhất team bạn làm gì?" → Đó là Mission
I
Input
Dữ liệu đầu vào Agent nhận được
💡 "Thiếu input này, agent có làm được không?" → Bắt buộc hay tùy chọn
C
Constraints
Quy tắc và giới hạn xử lý — Agent KHÔNG được làm gì?
💡 "Điều tệ nhất agent có thể làm sai?" → Đó là Constraint cần viết
R
Role
Vai trò và danh tính — persona, tone, chuyên môn
💡 "JD như vậy có ai apply không?" → Role phải đủ cụ thể
O
Output
Kết quả cụ thể Agent tạo ra — format, cấu trúc
💡 "Nhận output này, dùng được ngay không?" → Tốt = dùng ngay, không xử lý thêm

Python gửi JSON đã xử lý → Apps Script nhận request → Ghi vào Google Sheet

6 Bước — Từ Input Đến Google Sheet Thật

Giảng viên thực hiện live. Học viên theo dõi sheet thay đổi thời gian thực.

1

Tạo Google Sheet Admin

Admin Expense Tracker — header 7 cột chuẩn.

Date|Employee|Item Amount|Category|Status|AI Note
2

Apps Script — Backend

Extensions → Apps Script → hàm doPost(e)

function doPost(e) { // nhận POST, ghi sheet }
3

Deploy Web App

Deploy → Web App → Execute as Me → Anyone

script.google.com/ macros/s/XXX/exec
4

Python Tool

File send_to_sheet.py — dán URL /exec vào

url = "URL_EXEC" requests.post(url, json=data)
5

Prompt Finance Agent

Gửi prompt — agent phân loại, xuất JSON chuẩn 7 trường.

Bạn là AI Finance Agent >500k → cần chứng từ Xuất JSON 7 trường...
6

Chạy & Xem Kết Quả

Sheet cập nhật ngay! Agent + MCP + API chạy thật.

type data.json | python \ send_to_sheet.py {"success": true}

📝 Ghi Thông Minh
