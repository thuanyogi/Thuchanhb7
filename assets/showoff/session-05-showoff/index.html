Khung MICRO · MICRO Framework

MICRO — JD Cho Nhân Viên AI

The 5-component standard for building a well-functioning AI Agent

M
 Mission
Sứ mệnh
 Nhiệm vụ cụ thể của Agent là gì? Làm gì, cho ai, mục tiêu gì?
What exactly should the agent do, for whom, and why?		 "Nhân viên giỏi nhất team bạn làm gì?" → Đó là Mission
I
 Input
Đầu vào
 Dữ liệu đầu vào Agent nhận được — bắt buộc và tùy chọn.
All data the agent needs before starting work.		 "Thiếu thông tin này, agent có làm được không?" → Bắt buộc
C
 Constraints
Giới hạn
 Quy tắc và giới hạn — Agent KHÔNG được làm gì?
Rules and limits — what the agent must NOT do.		 "Điều tệ nhất agent có thể làm sai?" → Viết thành Constraint
R
 Role
Vai trò
 Vai trò, danh tính, persona, tone, chuyên môn của Agent.
Who the agent is — persona, expertise, communication tone.		 "JD như vậy có ai apply không?" → Role phải đủ cụ thể
O
 Output
Đầu ra
 Kết quả cụ thể Agent tạo ra — format, cấu trúc, tiêu chí.
Exact result format and quality criteria expected.		 "Nhận output này, dùng được ngay không?" → Tốt = dùng ngay
