## Phase Summary

- **Operate (1–4):** Learn the workspace, run PDCA, design first workflow
- **Modify (5–9):** Add agents, knowledge, rules, handoff, audit, debug
- **Create (10–11):** Build real business workflow end-to-end
- **Present (12):** Demo live, score against rubric
