# 📤 Outputs — Hướng Dẫn Sử Dụng

## Mục Đích

Thư mục `outputs/` chứa **tất cả kết quả** do AI Agent tạo ra.
Đây là nơi lưu trữ bằng chứng học tập và sản phẩm của bạn.

## Thư Mục Con

| Thư mục | Mô tả | Dùng từ buổi |
|---------|--------|-------------|
| `content-drafts/` | Nháp bài viết, caption, email do AI tạo | Buổi 3+ |
| `analytics-reports/` | Báo cáo phân tích dữ liệu | Buổi 8+ |

## Cách Đặt Tên File

Gợi ý format: `YYYY-MM-DD-mo-ta-ngan.md`

Ví dụ:
- `2024-07-01-linkedin-post-draft.md`
- `2024-07-02-monthly-report-june.md`

## Lưu Ý

- Giữ lại tất cả outputs — kể cả bản nháp chưa hoàn chỉnh
- Dùng để trình bày trong buổi demo cuối khóa (buổi 12)
- Có thể tạo thêm thư mục con nếu cần

---
> Outputs là **bằng chứng học tập** quan trọng nhất cho buổi trình bày cuối khóa.
