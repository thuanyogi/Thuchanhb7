# 🛠️ Scripts — Hướng Dẫn Sử Dụng

## Mục Đích

Thư mục `scripts/` chứa các **script hỗ trợ** tự động hóa tác vụ trong workspace.
Bạn sẽ tạo scripts từ **buổi 4** trở đi.

## Ví Dụ Scripts Có Thể Tạo

| Script | Mô tả | Ngôn ngữ |
|--------|--------|----------|
| `analyze-posts.py` | Phân tích hiệu quả bài đăng | Python |
| `generate-report.py` | Tạo báo cáo tự động | Python |
| `content-calendar.py` | Lên lịch đăng bài | Python |

## Cách Tạo Script Mới

1. Tạo file script trong thư mục này
2. Thêm mô tả vào bảng trên
3. Ghi lại kết quả chạy vào `docs/pdca-log.md`

## Lưu Ý

- Ưu tiên Python vì AI Agent hỗ trợ tốt nhất
- Luôn test script với dữ liệu mẫu trước
- Kết quả script nên lưu vào `outputs/`

---
> Scripts được tạo từ **buổi 4** khi bắt đầu workflows cơ bản.
