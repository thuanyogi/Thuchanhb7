# Quy Tắc Tiêu Chuẩn Hình Ảnh

## Bảng màu thương hiệu

| Tên màu | Mã hex | Sử dụng |
|---|---|---|
| Xanh chính (Primary Blue) | #2563EB | Tiêu đề, CTA button, link, icon chính |
| Vàng nhấn (Accent Amber) | #F59E0B | Highlight, badge, cảnh báo, số liệu nổi bật |
| Trắng nền (Background White) | #FFFFFF | Nền chính, khoảng trống |
| Xám đậm (Dark Gray) | #1F2937 | Nội dung văn bản chính |
| Xám nhạt (Light Gray) | #F3F4F6 | Nền phụ, đường kẻ, divider |
| Xanh nhạt (Light Blue) | #DBEAFE | Nền box highlight, callout |

## Font chữ

- **Font chính:** Be Vietnam Pro — dùng cho tiêu đề và nội dung.
- **Font phụ:** Inter — dùng cho số liệu, bảng biểu, code.
- **Cỡ chữ tiêu đề:** 24–32px (desktop), 20–24px (mobile).
- **Cỡ chữ body:** 16px (desktop), 14px (mobile).
- **Line height:** 1.6 cho body text.

## Quy tắc hình ảnh

- Ảnh phải rõ ràng, không bị mờ hoặc pixel vỡ.
- Ảnh chụp màn hình phải crop gọn, bỏ viền thừa.
- Infographic dùng bảng màu thương hiệu, font Be Vietnam Pro.
- Không dùng ảnh stock có watermark.
- Ảnh profile phải nhất quán trên tất cả nền tảng.
- Mọi ảnh lưu trong `outputs/assets/` với tên file mô tả rõ nội dung.
